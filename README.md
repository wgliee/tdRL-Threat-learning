
# mPFC Microcircuit and Behavioral Analysis Code Repository

This repository contains MATLAB source code and analysis pipelines accompanying the manuscript, focusing on prefrontal cortex (mPFC) microcircuits, STDP modeling, and behavioral reinforcement learning analyses.

Detailed descriptions and instructions can be found in the `README.md` file located inside each corresponding subfolder.
---

## Repository Structure

```text
.
├── Miniscope data analysis/   # Miniscope calcium imaging data processing and analysis scripts
├── STDP/                      # Leaky integrate-and-fire neural network models with STDP conditions
└── tdRL/                      # Trial-wise discount reinforcement learning (tdRL) behavioral models


## Requirements
- MATLAB R2021b or later
